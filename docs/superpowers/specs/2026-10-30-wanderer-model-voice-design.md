# 风起异途：模型设置与独立角色语音设计

## 目标

1. 双击 `start.bat` 后，本机能自动使用已安装的 GPT-SoVITS v2Pro，不因缺少 `.env` 而无声音或退回浏览器音色。
2. 公开 HTTPS 网站使用独立、持续在线的 GPT-SoVITS 语音服务。网站不依赖开发者电脑，访客也不需安装模型或下载权重。
3. 自由对话在移动端提供模型设置界面。用户使用自己的兼容模型 API Key，可主动选择是否记在当前设备。
4. 保留剧情旅途的离线固定剧情，不因自由对话的模型配置而改变。

## 架构

### 语音

语音始终由后端转发，浏览器只请求同源的 `/api/voice/stream`。

- 本机模式：只使用文档明确说明的一个默认安装根目录和一个默认参考音频，不搜索整个磁盘、多个猜测路径或不同版本。这一组约定默认值可在没有 `.env` 时使用；如未找到或文件无效，启动窗口和状态 API 必须显示可操作的原因和需配置的变量名。
- 非标准安装根目录或权重用 `GPT_SOVITS_ROOT` / `WANDERER_TTS_GPT_WEIGHTS` 指定；非标准参考音频用 `WANDERER_TTS_REFERENCE_AUDIO` 指定；非标准 API 地址/端口用 `WANDERER_TTS_API_URL` 指定。启动器不在这些配置失败后静默回退到浏览器音色。
- 本机配置失败必须返回结构化诊断：`code`、面向用户的原因、需要设置的变量名、当前检查项和下一步动作。启动器日志、`/api/voice/status` 和设置界面使用同一组诊断码；例如缺少参考音频时明确提示设置 `WANDERER_TTS_REFERENCE_AUDIO`，服务不可达时明确提示检查 `WANDERER_TTS_API_URL` 或启动对应服务。不得用“未找到，继续尝试其他目录”掩盖失败。
- 公开模式：部署环境配置一个 HTTPS GPT-SoVITS `/tts` 端点。该服务单独运行并保存训练权重、参考音频和提示文本；开发者电脑可关机、断网或不运行项目。
- 后端对远程 TTS 只使用部署方环境变量，不接受浏览器传入的 TTS URL，以避免 SSRF。本地 HTTP 只允许 loopback；远程端点必须是 HTTPS。
- 语音不可用时仍显示文本，并回传可识别的状态和配置指引。不静默播放浏览器语音；用户可主动选择系统语音作为临时兼容方式，并明确显示当前使用的是兼容音色。

### 自由对话模型

用户在界面中配置一个 OpenAI Chat Completions 兼容接口：

- 预设包含常见兼容服务商；自定义配置要求 HTTPS、模型 ID 和 API Key。
- `GET /api/model/providers` 只返回非敏感预设元数据。
- `POST /api/model/test` 仅测试当次配置，不保存 API Key。
- 自由对话请求携带临时模型配置。后端仅在当次请求中创建 `LiveModelClient`；数据库可保存非敏感的模型标签，但不保存 Key。
- SSE、重新生成和取消请求均使用同一个临时配置。模型错误不回退为固定 fixture 回复。

### 共享层与隔离层

两条产品路径共享传输和基础设施，但不共享领域状态或持久化消息模型。共享层只负责可复用的协议与资源能力：

- JSON 请求/响应封装、request ID、标准化错误码和不泄露凭据的日志边界。
- SSE 按协议边界各保留唯一帧解析器：后端供应商流解析器与浏览器应用流解析器分别处理各自的字节/事件契约；各边界内的消费者共用对应实现，不得在聊天、语音或页面路径中复制解析代码。统一请求取消基础设施与两种解析器配合工作。
- 上游 HTTP 传输的超时、状态码分类、响应文本净化和安全 URL 校验；自由对话的模型客户端在此基础上注入临时凭据。
- 同源语音接口、音频队列、播放/停止状态和“训练音色/兼容音色/无语音”的显示状态。

隔离层保留各自的领域契约和生命周期：

- 剧情旅途继续使用 `AIResponse`、`GameState`、`HistoryItem`、`RoleplayEngine` 及其状态机和离线回放；它不读取模型设置，不接收用户 API Key，也不复用自由对话的聊天历史。
- 自由对话使用独立的 `ChatResponse`、聊天历史、临时模型配置和模型错误动作；模型 Key 只允许进入自由对话路由的请求上下文，不得进入剧情路由、游戏状态或共享持久化层。
- 两条路径可以调用共享的 SSE/取消/语音能力，但不得为了复用而合并两套领域消息结构。新增字段应先落在对应领域契约中，再通过共享传输层承载。

### Key 的本地保存

- 默认仅存于当前页面内存，刷新后清除。
- 用户勾选“在此设备保存”后，前端才写入当前浏览器 `localStorage`；界面显示已保存并提供立即清除。
- “清除 Key”会清理应用所能控制的副本：移除 `localStorage` 和可能使用的 `sessionStorage` 项，清空设置字段与页面内存配置，并通过同源标签页通知让其他已打开页面同步清除和中止可取消请求。正在进行的测试、聊天或重试请求都必须绑定可取消信号；清除时全部取消。模型配置请求使用 `no-store`，应用不把 Key 写入 IndexedDB、Service Worker、URL、日志或应用请求缓存。
- 清除后应用释放所有可达的 Key 引用，但 JavaScript 引擎不提供对不可变字符串的可靠物理内存抹除保证，界面和文档不得声称完成了安全内存擦除。浏览器密码管理器、开发者工具网络记录、OS 备份及已发出的上游请求不受应用控制；界面不得承诺清理这些副本。应用需关闭 Key 字段自动填充并避免把 Key 放入表单历史。
- 由于后端代理模型请求，API Key 会经过网站服务器并在内存中短暂处理；站点运营者理论上可访问该请求。界面必须明示这点，用户只应在信任该站点时提交 Key。
- 兼容服务商可根据用户的 API Key 和套餐计费，模型设置页应提示相应费用由用户与其服务商结算。

## 安全边界

- 用户提供的模型 URL 拒绝 `http://`、回环/私网地址、URL 内嵌凭据和自动跟随重定向。
- 不在日志、异常文本、SSE 事件或诊断字段中返回 Key。
- 语音权重、参考音频、本机 `.env`、数据库和缓存均保持在 Git 忽略或部署秘密范围内。发布包不包含这些内容。
- 源码发布包仅收集 Git 已跟踪文件，不遍历打包器运行时的所有本地文件；未跟踪或 Git 忽略的文件即使不在已知秘密路径下，也不能被打包。

## 错误与回退

- 缺少模型配置时，保留草稿并提供“去模型设置”。
- HTTP 401/403：保留草稿，提供检查 API Key/权限的说明和“打开设置”，不自动重试。
- HTTP 400/404 或模型/端点无效：提示检查模型 ID 和接口地址，提供“编辑模型设置”。
- 超时、断网和上游 5xx：保留输入草稿并提供手动“重试”；限流时显示服务方提供的重试时间，避免意外重复调用。
- 无效或不安全的模型响应：说明回复未通过校验，保留原草稿并提供“重试”和“调整模型设置”，不回退 fixture。
- TTS 不可用时只影响声音，不丢失文字回复。
- 剧情旅途不使用用户的模型 Key，始终使用离线回放。

## 测试与验收

1. 本机无 `.env`、GPT-SoVITS API 已就绪时，`/api/voice/status` 可用，`/api/voice/stream` 返回 WAV，不调用浏览器 `speechSynthesis`。
2. 本机语音未就绪时，状态返回结构化原因、具体配置变量和下一步动作；文字仍可见，且不会静默切换到浏览器语音。
3. 公开 HTTPS 网站配置远程 TTS 后，访客只请求同源 API 并收到 WAV，开发者电脑离线时仍可用。
4. 移动端可选预设或自定义模型，测试连接后发送实时对话。
5. Key 未勾选时刷新丢失，勾选后刷新恢复；在一个标签页清除时，所有同源已打开标签页的字段、内存引用及在途请求均被清理/取消；应用存储与缓存中无残留 Key，服务端无 Key 持久化数据。
6. 401/403、400/404、超时/断网/5xx、限流和无效响应分别触发可断言的 UI 动作：打开设置、检查权限、手动重试或等待，不出现固定 fixture 回复。
7. 剧情旅途回归测试证明其离线状态机不读取自由对话配置；自由对话回归测试证明模型 Key 不进入剧情请求或持久化层。
8. 后端供应商流和浏览器应用流各只有一个对应的 SSE 解析实现，并覆盖分片、结束帧、解析失败和取消；自由对话使用浏览器应用流解析器，后端模型客户端使用供应商流解析器。剧情旅途继续使用 JSON/离线回放，不新增 SSE 解析代码。
9. 发布包测试在临时 Git 仓库中创建 Git 忽略文件，确认它们不会进入压缩包。

## 部署前置

公开运行时需为后端配置独立、持续在线的 TTS 服务：其中包含你的 GPT-SoVITS v2Pro 权重、参考音频和 HTTPS 反代理。该主机可能产生 GPU 或托管费用；开发者电脑不必持续开机。代码仓库只包含客户端、后端代理和部署文档，不包含权重、语音文件、Key、本机路径或数据库。
