# 风起异途：模型设置与独立角色语音设计

## 目标

1. 双击 `start.bat` 后，本机能自动使用已安装的 GPT-SoVITS v2Pro，不因缺少 `.env` 而无声音或退回浏览器音色。
2. 公开 HTTPS 网站使用独立、持续在线的 GPT-SoVITS 语音服务。网站不依赖开发者电脑，访客也不需安装模型或下载权重。
3. 自由对话在移动端提供模型设置界面。用户使用自己的兼容模型 API Key，可主动选择是否记在当前设备。
4. 保留剧情旅途的离线固定剧情，不因自由对话的模型配置而改变。

## 架构

### 语音

语音始终由后端转发，浏览器只请求同源的 `/api/voice/stream`。

- 本机模式：后端优先重用 `127.0.0.1:9880` 的 GPT-SoVITS，没有 `.env` 时自动检测默认安装目录和默认参考音频。启动器在需要时启动本机 API。
- 公开模式：部署环境配置一个 HTTPS GPT-SoVITS `/tts` 端点。该服务单独运行并保存训练权重、参考音频和提示文本；开发者电脑可关机、断网或不运行项目。
- 后端对远程 TTS 只使用部署方环境变量，不接受浏览器传入的 TTS URL，以避免 SSRF。本地 HTTP 只允许 loopback；远程端点必须是 HTTPS。
- 语音不可用时仍显示文本，并返回可识别的语音状态。浏览器语音只作兼容回退，不再伪装为训练音色。

### 自由对话模型

用户在界面中配置一个 OpenAI Chat Completions 兼容接口：

- 预设包含常见兼容服务商；自定义配置要求 HTTPS、模型 ID 和 API Key。
- `GET /api/model/providers` 只返回非敏感预设元数据。
- `POST /api/model/test` 仅测试当次配置，不保存 API Key。
- 自由对话请求携带临时模型配置。后端仅在当次请求中创建 `LiveModelClient`；数据库可保存非敏感的模型标签，但不保存 Key。
- SSE、重新生成和取消请求均使用同一个临时配置。模型错误不回退为固定 fixture 回复。

### Key 的本地保存

- 默认仅存于当前页面内存，刷新后清除。
- 用户勾选“在此设备保存”后，前端才写入当前浏览器 `localStorage`；界面显示已保存并提供立即清除。
- 由于后端代理模型请求，API Key 会经过网站服务器并在内存中短暂处理；站点运营者理论上可访问该请求。界面必须明示这点，用户只应在信任该站点时提交 Key。
- 兼容服务商可根据用户的 API Key 和套餐计费，模型设置页应提示相应费用由用户与其服务商结算。

## 安全边界

- 用户提供的模型 URL 拒绝 `http://`、回环/私网地址、URL 内嵌凭据和自动跟随重定向。
- 不在日志、异常文本、SSE 事件或诊断字段中返回 Key。
- 语音权重、参考音频、本机 `.env`、数据库和缓存均保持在 Git 忽略或部署密秘范围内。发布包不包含这些内容。
- 源码发布包仅收集 Git 已跟踪文件，不遍历打包器运行时的所有本地文件；未跟踪或 Git 忽略的文件即使不在已知秘密路径下，也不能被打包。

## 错误与回退

- 缺少模型配置时，界面引导用户打开模型设置，不再静默使用固定回复。
- 模型提供方超时、权限失败、限流、协议不兼容分别返回可识别的错误。
- TTS 不可用时只影响声音，不丢失文字回复。
- 剧情旅途不使用用户的模型 Key，始终使用离线回放。

## 测试与验收

1. 本机无 `.env`、GPT-SoVITS API 已就绪时，`/api/voice/status` 可用，`/api/voice/stream` 返回 WAV，不调用浏览器 `speechSynthesis`。
2. 本机语音未就绪时，状态返回原因，文字仍可见。
3. 公开 HTTPS 网站配置远程 TTS 后，访客只请求同源 API 并收到 WAV，开发者电脑离线时仍可用。
4. 移动端可选预设或自定义模型，测试连接后发送实时对话。
5. Key 未勾选时刷新丢失，勾选后刷新恢复，清除后丢失；服务端无 Key 持久化数据。
6. 剧情旅途、既有流式聊天和发布包排除规则通过回归测试。
7. 发布包测试在临时 Git 仓库中创建 Git 忽略文件，确认它们不会进入压缩包。

## 部署前置

公开运行时需为后端配置独立、持续在线的 TTS 服务：其中包含你的 GPT-SoVITS v2Pro 权重、参考音频和 HTTPS 反代理。该主机可能产生 GPU 或托管费用；开发者电脑不必持续开机。代码仓库只包含客户端、后端代理和部署文档，不包含权重、语音文件、Key、本机路径或数据库。
