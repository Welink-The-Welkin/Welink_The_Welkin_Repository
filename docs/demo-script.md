# 演示流程

## 离线演示

1. 从首页进入自由对话；打开“模型设置”，选择服务商预设或填写兼容接口、模型 ID 和 API Key，按需勾选在此设备记住设置。
2. 进入自由对话，发送一条普通消息；展示玩家消息即时落位、角色回复淡入、主题标题和可恢复历史，并演示删除一条历史会话。
3. 回到首页进入剧情目录，选择故事线、填写玩家名字、查看前情概要，再按当前回合选项推进。剧情使用本地固定内容。
4. 完成八个回合，展示状态指标会随选择变化，并走到不同结局 ID、标题、摘要和旅途收束文案。
5. 刷新页面验证对应自由聊天记录或剧情存档恢复。

离线自由对话根据关键词给出确定性示范回应；剧情使用确定性模型和状态机完整推进八个回合。两者都不声称是现场模型生成。

## 实时演示

进入自由对话后在“模型设置”中填写模型接口，点击“测试连接”确认 API 凭据和模型额度可用，再发送消息验证模型服务；展示角色输出符合 `docs/role-authority.md`；剧情旅途使用本地剧情，玩家选择会影响场景或结局。若服务超时或不可用，系统显示对应错误，不将其伪装成成功回复。

## 故障处理

- 页面未加载：确认 PowerShell 服务仍运行，再刷新 `http://127.0.0.1:8000`。
- 电脑刚重启：先双击项目目录中的 `start.bat`，等待健康检查完成后再刷新页面。
- 模型报错：页面会显示 HTTP 错误类别及不含密钥和查询参数的诊断信息。403 时请服务商核查账号或模型权限、IP 白名单和接口访问策略；不要仅凭状态码就更换密钥。其他问题检查模型标识、端点、额度和网络；自由对话演示可切回离线模式。
- 存档恢复失败：重新开始对应模式，并确认浏览器仍允许本地存储。
- 现场需证明 CodeArts 使用：仅展示真实 IDE 对话、修改和运行记录；本工作区的记录不能作为 CodeArts 过程截图。
